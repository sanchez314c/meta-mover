# META Mover Build Resources

This directory contains all build-related resources and configuration files for creating cross-platform META Mover distributions.

## Directory Structure

```
build-resources/
├── README.md                          # This file
├── build-info.json                    # Build configuration summary
├── entitlements.mac.plist             # macOS main app entitlements
├── entitlements.mac.inherit.plist     # macOS child process entitlements
├── notarize.js                        # macOS notarization script
├── generate-placeholder-icons.sh      # Icon generation utility
└── icons/
    ├── README.md                      # Icon requirements and guidelines
    ├── MANUAL_CREATION.md             # Manual icon creation instructions
    ├── icon.icns                      # macOS icon bundle
    ├── icon.ico                       # Windows icon
    ├── icon.png                       # Linux main icon (512x512)
    ├── 16x16.png                      # Small icon variants
    ├── 32x32.png
    ├── 48x48.png
    ├── 64x64.png
    ├── 128x128.png
    ├── 256x256.png
    └── 512x512.png
```

## Files Overview

### Core Build Resources

**entitlements.mac.plist**
- Main macOS application entitlements for sandboxing
- Configured with network access, file system permissions, and JIT compilation
- Required for macOS App Store distribution and notarization

**entitlements.mac.inherit.plist**  
- Child process entitlements for Electron helper processes
- Inherits basic sandbox and JIT permissions from main app

**notarize.js**
- Automated macOS notarization script integrated with electron-builder
- Supports both Apple ID and API Key authentication methods
- Handles error cases and provides helpful debugging information

### Utilities

**generate-placeholder-icons.sh**
- Automated icon generation script using ImageMagick
- Creates placeholder icons in all required formats and sizes
- Provides fallback instructions for manual creation

**build-info.json**
- Complete build configuration summary and documentation
- Platform support matrix and status tracking
- Development notes and next steps for production builds

### Icons Directory

**Comprehensive Icon Set**
- All formats required for cross-platform distribution
- macOS: ICNS bundle with Retina support
- Windows: Multi-resolution ICO file
- Linux: PNG files in standard freedesktop.org sizes

**Current Status**: Placeholder icons generated by script
**Production Ready**: ❌ Requires professional META Mover branding

## Usage Instructions

### 1. Icon Generation

Generate placeholder icons (requires ImageMagick):
```bash
cd build-resources
./generate-placeholder-icons.sh
```

For manual icon creation:
```bash
# Read the comprehensive guidelines
cat icons/README.md
cat icons/MANUAL_CREATION.md  # If ImageMagick unavailable
```

### 2. Build Integration

Icons and entitlements are automatically integrated via package.json configuration:

```json
{
  "build": {
    "mac": {
      "icon": "build-resources/icons/icon.icns",
      "entitlements": "build-resources/entitlements.mac.plist",
      "entitlementsInherit": "build-resources/entitlements.mac.inherit.plist"
    },
    "win": {
      "icon": "build-resources/icons/icon.ico"
    },
    "linux": {
      "icon": "build-resources/icons/"
    }
  }
}
```

### 3. Code Signing & Notarization

**macOS Setup**:
```bash
# Set environment variables for notarization
export APPLE_ID="your-apple-id@example.com"
export APPLE_PASSWORD="app-specific-password"
export APPLE_TEAM_ID="YOUR_TEAM_ID"

# Or use API Key (recommended for CI/CD)
export APPLE_API_KEY="/path/to/AuthKey_KEYID.p8"
export APPLE_API_KEY_ID="YOUR_KEY_ID"
export APPLE_API_ISSUER="YOUR_ISSUER_ID"
```

**Windows Setup**:
```bash
# Optional: Set code signing certificate
export CSC_LINK="/path/to/certificate.p12"
export CSC_KEY_PASSWORD="certificate_password"
```

### 4. Build Process

Run the complete build process:
```bash
# Execute full multi-platform build
./scripts/compile-build-dist.sh

# Check for bloat and optimize
./scripts/bloat-check.sh

# Clean temporary files
./scripts/temp-cleanup.sh
```

## Platform-Specific Notes

### macOS
- **Entitlements**: Configured for sandbox compatibility and App Store distribution
- **Notarization**: Required for distribution outside App Store
- **Code Signing**: Requires valid Apple Developer certificates
- **Universal Binaries**: Supports both Intel (x64) and Apple Silicon (arm64)

### Windows
- **Code Signing**: Optional but recommended for user trust
- **Installer Types**: NSIS (.exe), MSI, APPX (Microsoft Store), Portable
- **Architectures**: x64, ia32, arm64 support
- **File Associations**: Configured in package.json

### Linux
- **Distribution Formats**: AppImage, DEB, RPM, Snap, TAR archives
- **Desktop Integration**: .desktop file generation and icon installation
- **Dependencies**: Minimal system requirements for broad compatibility
- **Architecture Support**: x64 and arm64

## Troubleshooting

### Common Issues

**Icon Generation Fails**:
- Install ImageMagick: `brew install imagemagick` (macOS)
- Use manual creation instructions in `icons/MANUAL_CREATION.md`
- Verify icon file formats and sizes

**Code Signing Issues**:
- Check certificate validity and expiration
- Verify keychain access (macOS) or certificate store (Windows)
- Ensure proper environment variable configuration

**Notarization Fails**:
- Verify Apple credentials and team ID
- Check for temporary Apple service issues
- Review error messages for specific guidance

**Build Size Too Large**:
- Run `./scripts/bloat-check.sh` for analysis
- Review dependencies and remove unused packages
- Enable webpack optimization and tree-shaking
